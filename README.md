# Credit Spread Modelling
This repository is a centralized place for all credit spread modelling. The focus on this repo is to replicate and model credit spreads. As the model and research is conducted there are some occassionaly strategies which will be placed in ```notebooks\2Strategies```.  The original format of this strategy was to build and replicate the Duration Time Spread models from the Barclays Team.
